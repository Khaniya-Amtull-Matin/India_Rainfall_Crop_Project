# India Rainfall & Crop Production Analysis (1997–2015) 🌾🌧️

An interactive data analysis and visualization dashboard built using Python, Plotly, Dash, and Pandas. This project analyzes the historical relationship between seasonal/annual rainfall patterns and crop yield across various states and districts in India.

## 📌 Project Overview
- **Domain:** Food & Agriculture / Climate Analytics
- **Dataset:** India Rainfall & Crop Yield Data (1997–2015)
- **Key Focus:** Visualizing state-wise crop production trends, rainfall distributions, and assessing agricultural impact.

---

## 🛠️ Tech Stack & Dependencies
- **Programming Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Plotly Express, Plotly Graph Objects
- **Web Framework:** Dash (Dash Core Components, Dash HTML Components)
- **Version Control:** Git, GitHub Desktop

---

## 🚀 Key Features of Dashboard
- **Dynamic Year & State Filtering:** Interactive Range Slider synchronized with numeric input fields to select year ranges.
- **Multi-Metric Analytics:** View production trends across different crop types and seasons.
- **Export Data Feature:** Filtered datasets can be exported directly to CSV.
- **Responsive Dark Theme UI:** Custom styled components for an intuitive, modern user experience.
